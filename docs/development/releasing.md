# Releasing goreg

goreg is released with [Hephaestus](https://github.com/magicdrive/hephaestus)
(`hephaestus.yaml`). Pushing a `v*` tag runs `.github/workflows/release.yml`,
which publishes the GitHub Release and opens a pull request on
[magicdrive/homebrew-tap](https://github.com/magicdrive/homebrew-tap). Nothing
is published from a pull request or from a workstation.

## Prerequisites (repository settings)

- Environment `release`, deployment restricted to tags `v*`, holding the
  secret `HOMEBREW_TAP_GITHUB_TOKEN`: a fine-grained token (or GitHub App
  token) with `contents: write` and `pull-requests: write` on
  `magicdrive/homebrew-tap` only.
- The release itself uses the workflow's `GITHUB_TOKEN`
  (`contents: write` in the `release` job only). `PERSONAL_GITHUB_TOKEN` is
  no longer used.

## Steps

1. Merge everything for the release into `main` and wait for CI to pass.
2. Run the read-only preflight for the tag (git state, CI on the commit, the
   release workflow and environment, the tap):

   ```sh
   GITHUB_TOKEN="$(gh auth token)" make preflight tag=vX.Y.Z
   ```

3. Push the tag. `make publish tag=vX.Y.Z` runs the same preflight, then
   creates and pushes the tag.
4. Watch the `Release` workflow: `ci` (the full CI at the tag), `build`
   (build, archive, checksum; read-only) and `release` (tap dry run,
   provenance attestation, GitHub Release, tap pull request).
5. Review and merge the pull request "Brew formula update for goreg version
   vX.Y.Z" on magicdrive/homebrew-tap.

Release notes are generated by GitHub from the merged pull requests.
Prerelease tags (`vX.Y.Z-rc.1`) are published as prereleases and do not
update the tap.

## What a release contains

Unchanged from the GoReleaser releases up to v1.3.10, and checked by
`scripts/verify-dist.sh` in CI and before publishing:

- `goreg_<version>_<os>_<arch>.tar.gz` for darwin/amd64, darwin/arm64,
  linux/386, linux/amd64, linux/arm64, windows/386, windows/amd64 and
  windows/arm64 (tar.gz on Windows too), each with `goreg` (`goreg.exe`) at
  the root and `completions/` (`goreg-completion.sh`,
  `bash/goreg-completion.bash`, `zsh/_goreg`);
- `goreg_checksums.txt` (`sha256sum -c` format);
- `goreg --version` prints `goreg version vX.Y.Z`.

`make snapshot` builds the same files locally (version `0.0.0-SNAPSHOT`).

## Recovery

- **The workflow failed before `Publish the GitHub Release`:** nothing is
  public. Fix the cause on `main`; delete and re-push the tag only if the fix
  must be part of the release, otherwise re-run the failed jobs.
- **It failed after the release was published:** re-run the failed jobs.
  Hephaestus continues idempotently: identical assets are left alone, and the
  tap pull request is reused. A published release's assets are never
  replaced; release a new patch version instead.
- **The tap pull request was not opened:** re-run the `release` job, or from
  a clone of the tag with the downloaded `dist` artifact:
  `hephaestus run --stages formula,tap` with `HOMEBREW_TAP_GITHUB_TOKEN` set.

See the Hephaestus [recovery guide](https://github.com/magicdrive/hephaestus/blob/v1.1.0/docs/recovery.md).
